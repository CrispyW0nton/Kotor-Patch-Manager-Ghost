# Custom Animation K2 Drexl Test

This development-only patch is the first KOTOR 2 proof for Issue #98. It
registers the custom name `kpm_drx_a1` as ID `65000` and maps selected idle and
attack requests to it only for the `C_DrexlF` model.

The core performs a model-chain availability check before replacing a name. If
`kpm_drx_a1` is absent or malformed, KOTOR 2 keeps the original animation
request instead of being forced into a missing-animation fallback.

The final package will include `c_drexlf.mdl` and `c_drexlf.mdx` generated by
Ghost Studio. The base model should remain byte-preserved wherever possible;
only the local animation table and appended animation payload should change.
It also includes the uniquely named `kpm98_drx.utc` test creature. No PLCaa
module resource is replaced.

The live debugger is intentionally passive: it attaches through the Windows
debug API and fingerprints loaded game-local modules without installing or
replacing proxy DLLs used by the active mod list.

Rebuild the probe asset from the local stock K2 installation and the sibling
Ghost Studio workspace with:

```powershell
py tools/build_k2_drexl_animation_probe.py
```

Expected DebugView evidence for a successful test:

```text
[CustomAnimationCore] Gob::PlayAnimation REGISTER_MAPPED ... resolved=kpm_drx_a1 ...
[CustomAnimationCore] Gob::PlayAnimation STACK_MAPPED ... resolved=kpm_drx_a1
[CustomAnimationCore] AnimRun CREATE ... name=kpm_drx_a1 duration=...
```

For the live K2 test, load or warp to `plcaa`, open the cheat console, and run:

```text
dm_spawncreature kpm98_drx
```
